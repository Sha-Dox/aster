# Changelog

All versions below are development releases. No production-ready public binary is currently published.

## 0.5.0

- Selection-based Formalise in the composer and reply assistant.
- Editable complete-email preview with explicit use or send acceptance.
- Native text selection, preserved recipients, attachments and existing subject.
- Clear Liquid Glass, transparent window backing and native desktop blur.
- Clear, frosted and solid appearance choices with accessibility fallbacks.
- Separate keyboard shortcuts for synchronization and AI replies.
- Additional formalisation regression and opt-in on-device model coverage.

## 0.4.0

- Instruction-driven reply generation with editable preview and explicit acceptance.
- Configurable language, tone, length, custom instructions and signature.
- Per-account writing preferences and account/session isolation for previews.

## Earlier development work

- Native Microsoft and Google authentication and synchronization.
- Multiple accounts, unified Priority inbox and per-account Junk policies.
- Local SQLite cache, search, durable offline changes and draft autosave.
- Bcc, attachment handling, HTML isolation and conservative send retries.
